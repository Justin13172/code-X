# 科学育儿知识体系

为小狮子（1 岁，中国大陆，祖辈参与看护）建立的一套育儿判断体系。

**建立于 2026-08-03。** 具体月龄与情况见 [live/profile.md](live/profile.md)。

---

## 这是什么

**不是一本育儿百科，是一个过滤器。**

育儿的真实困境不是信息太少，是太多、且无法分辨真假。再写一本百科只会加剧问题。所以这套体系的结构是：

```
少量稳定的判断规则（终身有效）
        ↓
一份很薄的行动清单（按期望收益排序，随年龄更新）
        ↓
跨会话持续读写的活档案
```

**规则可以压缩，事实不能。** 所以核心投资在规则上。

**成功标准**：你的待办清单**变短**、焦虑下降，同时高价值的事项一件不漏。
如果哪天这份文档读起来像「又多了一堆任务」，说明它失败了，需要重新裁剪。

## 怎么用（两种模式）

### 模式一：随时咨询

遇到具体问题直接问。**每次回答都按固定格式**，以保证严谨性不随会话漂移：

```
1. 直接结论（一句话）+ 置信度（高 / 中 / 低）
2. 依据：证据等级 + 关键研究（设计、样本量、效应量）
3. 不确定性与反方证据
4. 具体怎么做
5. 什么情况下应该推翻这个结论
```

第 3 和第 5 条是刻意保留的——**没有反方证据和证伪条件的回答，是不合格的回答**。

置信度的定义：

- **高** = 多个独立的高质量设计结论一致
- **中** = 方向一致，但设计有限或效应量不确定
- **低** = 单一研究或设计薄弱，仅供参考，不足以据此行动

### 模式二：主动推进

我从 [live/questions.md](live/questions.md) 取题，做求证和筛选，把结论写进对应文件，并在 [live/decisions.md](live/decisions.md) 留痕。

---

## 维护约定

1. **每条非显然的结论都要带**：出处 + 研究设计 + 样本量 + 效应量 + 置信度。写不出效应量的，明确写「效应量未知」。
2. **时效性条目标注核查日期**（疫苗、政策、补剂建议）。**超过一年未核查的，视为过期。**
3. **结论被新证据推翻时**：直接改，并在 `live/decisions.md` 记录改动原因。git history 就是变更记录，不另建 changelog。
4. **随时可以推翻我。** 如果某条结论你觉得不对，提出来。这套体系的价值在于可证伪，不在于权威。

## 边界声明

**这是一个证据评估框架，不是诊断工具，不能替代医生。**

以下情况请直接就医，不要在这里或任何网上内容中找答案：

- 急性症状：发热、呼吸困难、持续呕吐腹泻、外伤、疑似误服
- [02 中列出的任何发育预警信号](02-now-12-24m.md)
- 任何用药决策

本文件中关于疫苗、营养补充、药物的内容，是**帮助你和医生更好地沟通**的背景知识，不是处方。
