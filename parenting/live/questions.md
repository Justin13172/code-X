## 我需要你确认的（按优先级）

### 🔴 现在最缺、且最影响判断

- [ ] **当前身高**（最近一次医院测量还是 2026-06-13 的 73.5 cm）——判断是否已影响线性生长
- [ ] **睡眠状况**：夜间时长、夜醒次数、是否因痒醒。
      ⚠️ 优先级已提高：**瘙痒导致的睡眠碎片化会影响生长激素分泌**，在当前情况下不再是次要问题
- [ ] **执行反馈**：加稠、加油、加到 3 顿之后，吃得下吗？2 周后体重有没有动？

### 🟠 影响面最大

- [ ] **12 月龄是否会用手指指东西？**（尤其是为了给你看某样东西，而不只是要东西）
      这是发育筛查中价值最高的单项信号
- [ ] **家庭安全改造做了哪些？** 纽扣电池、家具上墙、窗户限位器——做一次就长期有效
- [ ] **安全座椅是不是每次都用？** 包括短途、包括老人带出门的时候
- [ ] **白天主要由谁带？祖辈参与到什么程度？**
      ⚠️ 这一条现在有了具体抓手：**海鲜回避的实际来源是「祖父海鲜过敏」**，
      说明祖辈的经验正在影响喂养决策。恢复海鲜时可能需要沟通，见 [04](../04-grandparent-care.md)

### 🟡 需要背景信息

- [ ] 出生孕周（是否足月）
- [ ] 会说的有意义的词大概几个；是否会独走
- [ ] 添加糖、果汁的情况；是否允许自主抓握进食
- [ ] AD 制剂的**具体产品与剂量**（涉及维生素 A 叠加的精确计算）
- [ ] 有没有计划送托？大概什么时候？
