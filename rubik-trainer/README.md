# 三阶魔方 · 1 小时入门（交互式 3D 教学工具）

为「空间感弱、零基础、又想快速学会三阶魔方打乱复原」的人做的工具。
**理解优先，不死记公式**：每一步都先讲原理，再用可旋转的 3D 魔方做慢放、高亮的动态演示。
最后用「打乱 → 跟我练」在真实随机打乱上一步步把它转回去。

## 怎么打开

这是一个纯前端、零构建的小项目（用了 three.js 做 3D）。因为用到 ES 模块，
需要用一个本地小服务器打开（不能直接双击 `index.html`）：

```bash
cd rubik-trainer
python3 -m http.server 8000      # 或者：npx serve .
```

然后浏览器访问 <http://localhost:8000> 。需要联网加载 three.js（首屏一次）。

## 怎么用（建议的 1 小时路线）

界面顶部有「学习路线」进度条，左侧面板分两种模式：

- **学习模式**：8 节微课。每节左边讲原理，点 **▶ 播放本节演示** 看 3D 慢放 + 高亮；
  也能用 **下一拍 ›** 逐拍看。建议按顺序过一遍：
  - 0–10 min：① 认识魔方（中心块/棱块/角块）② 转动记号 ③ 路线图
  - 10–25 min：④ 白十字 ⑤ 白角（第一层）
  - 25–35 min：⑥ 中层棱块
  - 35–50 min：⑦ 黄十字 ⑧ 顶层收尾
- **练习模式**：点 **🎲 打乱** 生成随机打乱，然后
  - **自动演示复原**：分阶段、带字幕地演示一整次复原；
  - **跟我练（逐步）**：每按一次 **下一步 ›** 转一步，面板提示当前阶段、剩余步数和下一步要转哪个面。

底部还有手动转面按钮（U/F/R/L/D/B 及其逆向）、速度切换、复位视角。鼠标拖动可任意换角度看。

## 它是怎么实现的（给好奇/想改的人）

- `src/cubeModel.js`：**几何块模型**——把魔方表示成 26 个小方块，转面就是旋转某一层的坐标与朝向。
  直观、可验证（`U` 转 4 次必还原、打乱+逆序必还原等）。
- `src/cube3d.js`：**three.js 渲染层**。颜色方案与转面方向和 `cubeModel` 完全一致，
  所以「看到的」和「算出来的」始终同步。
- `src/faceletEngine.js`：求解器用的**快速贴纸模型**（54 元素数组 + 预算好的置换表，
  从几何模型自动推导，保证一致），让深度搜索很快。
- `src/solverLBL.js`：**层先法求解器**。底层十字/角块用带锁定的迭代加深搜索逐块归位；
  中层用标准左右插入；顶层用「宏 BFS」在 `{U, U', 算法}` 上搜到目标——
  对任意打乱都能给出分阶段、可解释的还原路线。
- `src/lessons.js`：8 节课的原理讲解与演示脚本。
- `src/main.js` / `src/ui.js`：把上面这些串成界面。

## 自测

```bash
npm test       # = node test/run.mjs
```

会做：每个面转 4 次还原、打乱+逆序还原、sexy move ×6 还原、
以及**对 1000 个随机打乱跑求解器并验证全部能复原**。
